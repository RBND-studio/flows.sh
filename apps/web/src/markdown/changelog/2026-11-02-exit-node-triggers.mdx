---
title: Exit node triggers
date: "2026-11-02"
description: Move users through a workflow when their user properties change or after a set time, without waiting for them to click.
---

Exit nodes can now have extra triggers that move a user on without any interaction with the block. Add a **User properties** trigger to continue once the user's properties match your conditions, or a **Delay** trigger to continue after a set time since the user entered the block. Find both under **Trigger** in the exit node detail of components, surveys and tours.

You can use this to close an onboarding checklist as soon as the user finishes setup in your app, or to let a banner dismiss itself after 7 days so it doesn't sit there forever. Learn more about [exit node triggers](/docs/workflows/configure-blocks#triggers).

## SDK

- The survey popover now fits on screens narrower than the popover.
- Long values in the debug panel now wrap.
