## Overview

Note blocks let you annotate a workflow with comments, explanations, or reminders for yourself and your team. Notes only appear in the workflow editor. End users never see them, and they don't affect the workflow's execution in any way.

## Adding a note

Add a note from the **Notes** category in the add block panel. A note has a title and a description, both of which you edit directly on the block, and changes save automatically as you type.

## Behavior

- Notes aren't connected to other blocks with paths and don't have entry or exit nodes.
- Notes don't have a properties panel. All editing happens directly on the note itself.
